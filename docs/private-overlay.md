# Private overlay boundary

The public core owns schemas, migrations, validation, analytics contracts,
synthetic fixtures, and reproducibility controls.

A private installation owns:

- real health records and narratives;
- personal goals and analysis target values;
- source credentials and external account mappings;
- device, host, and deployment configuration;
- trainer names, workbook identifiers, proprietary layouts, and parsing maps;
- vendor-specific connector code until it is independently reviewed for public
  release; and
- source audit reports that could identify a person.

The overlay may depend on the public core. The public core must never depend on
the overlay.
